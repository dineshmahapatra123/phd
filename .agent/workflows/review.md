# Workflow: Review P-Lens

**Slash Command**: `/review`
**Description**: Triggers a comprehensive PhD-aligned review of a book or paper using the `review-p-lens` skill.

## Steps

1. **Check Source**: Ensure the target `.pdf` has a corresponding `.md` in `9 - Knowledge_base/sources/`.
2. **Apply Lens**: Read `9 - Knowledge_base/PHD_LENS.md`.
3. **Execute Review**: Invoke the `review-p-lens` skill logic to generate the full review.
4. **Save**: Write the final document to `1 - Rough/Review/gemini/<AuthorYear_ShortTitle>.md`.

---
*Note: This workflow is optimized for Antigravity's multi-tool capabilities.*
